So, I recently entered my first game jam.

A couple of weeks ago [molegato](https://molegato.com/) [announced on Bluesky](https://bsky.app/profile/molegato.com/post/3mwqkouajtc2p) he’d be hosting a game jam for [Halloween](https://molegato.com/halloween-gamejam-2026/). The theme for this one was “evil videogame copy”, which I took it to mean “a game that is darker than it seems at first glance”.

My entry to the jam is called “Theodore’s Great Hunt”.

{% image section=category, slug=postSlug %}
title.png | | Title screen for “Theodore’s Great Hunt” | pixelated
{% endimage %}

The gameplay is very similar to “Duck Hunt” for the NES. In the game, you need to hit a certain amount of targets per “round” via point-and-click shooter mechanics. If you succeed surpassing the minimum required, you can proceed to the next “level”.

For the art-style I wanted to make something GameBoy inspired, so I limited myself to a few colors per level. I looked into the Wario Land games specifically, since I wanted to make something of an adventurer/treasure-hunter character, although Theodore is a little more proper.

It’s a very short game, so proceed with that in mind. Since it was made in a week, you can think of it closer to a Mario Party minigame.

If you’d like to, you can try it out [for yourself](https://kulugary.itch.io/theodores-great-hunt)! I’d love to hear what you thought about it.
